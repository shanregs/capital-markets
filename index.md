# Capital Markets — Self-Paced Learning Path — Index

Master index for all module files. See [`capital_markets_self_paced_learning_path.md`](./docs/1-capital-markets/capital_markets_self_paced_learning_path.md) for the full original curriculum (all 14 modules, study method, and priorities) in one document. As each module gets its own expanded write-up (with extra examples, numbers, actor tables, and diagrams), it's linked below.

Modules 4–9 form the **Asset Class Roadmap** — Equity, Fixed Income, FX, Commodities, Rates, and Credit, each studied one at a time through the same eight-part pattern (What is it → Products → Security vs. Contract → Real trade example → Trade lifecycle → Identifiers → Exchange vs OTC/Bilateral/Cleared → Regulatory perspective). **Module 15 (Listed Derivatives)** sits apart from that roadmap — it's cross-cutting (Futures &amp; Listed Options on any of the six asset classes' underlyings), matching the work data model taxonomy's own "7. Listed Derivatives" node.

Example bank used throughout every module: **Bank Of Toronto** (fictional, for illustration only).

Also see: [**Abbreviations Glossary**](./docs/1-capital-markets/abbreviations.md) ([HTML](./docs/1-capital-markets/abbreviations.html)) — the most commonly used capital markets acronyms (identifiers, market structure, products, rates, valuation, settlement, risk, regulation) in one lookup reference.

Also see: [**Systems Landscape**](./docs/1-capital-markets/systems-landscape.md) ([HTML](./docs/1-capital-markets/systems-landscape.html)) — the actual Front/Middle/Back Office systems, data flows, and settlement cycles used in Canada, the US, the UK, and the EU, plus the regulatory bodies in each.

Modules 16–24 are **deep-dive/reference modules** — each expands one topic already touched on by Modules 1–15 into its own full write-up (theory, worked examples with real numbers, an actors cast, and a recap quiz), rather than adding a new asset class or lifecycle stage. See the Modules table below.

Also see: [**Complete OTC Derivative Lifecycle — USD/CAD FX Forward**](./docs/1-capital-markets/module-24-otc-derivative-usd-cad-forward-complete-lifecycle.md) ([HTML](./docs/1-capital-markets/module-24-otc-derivative-usd-cad-forward-complete-lifecycle.html)) — one Bank Of Toronto FX Forward taken through every operational stage at once (Trade Capture → Confirmation → Enrichment → Valuation → MTM → Collateral → Settlement → Regulatory Reporting), system by system and field by field, closing with a suggested microservices/event-driven architecture.

## Conventions for every module

- Each module file follows: **Concept → Real trade example (with numbers) → Actors involved → ASCII flow diagram → Takeaway → Recap quiz.**
- Example bank is always **Bank Of Toronto** — never the real bank name.
- Each `.md` module has a matching `.html` version (same content, styled as a standalone page) once built.
- Update this table's **Status** and links as new modules are written.
